## Описание

Когда вы наводите курсор на значок Spotify на панели задач, Windows показывает миниатюру с кнопками «назад», «пауза» и «вперёд», но громкость там изменить нельзя. Preview Volume добавляет прямо над этой миниатюрой небольшую полоску с ползунком, процентами и кнопкой отключения звука.

Windows разрешает добавлять кнопки в миниатюру только самому приложению, а Spotify уже использует свои. Поэтому Preview Volume рисует собственное маленькое окно рядом с миниатюрой и меняет громкость Spotify в **микшере громкости Windows**, а не ползунок внутри Spotify (они действуют вместе).

Это крошечная программа (около 40 КБ): живёт рядом с часами, никогда не выходит в интернет и почти не расходует ресурсы.

## Возможности

- **Ползунок громкости** над миниатюрой, той же ширины.
- **Колесо мыши** над миниатюрой или полоской: громче или тише с шагом 2 %.
- **Щелчок по динамику** отключает или включает звук.
- Скрывается сама, когда вы уводите курсор, и не пропадает, пока вы переходите от миниатюры к полоске.
- Параметр **«Показывать для всех приложений со звуком»**: Chrome, Brave, плееры… (по умолчанию только Spotify).
- Значок в области уведомлений и, по желанию, **запуск вместе с Windows**.
- Работает с несколькими мониторами и любым масштабом экрана (100 %, 150 %, 200 %…).

## Установка

1. Скачайте **`PreviewVolume-Setup.exe`** со [страницы релизов](https://github.com/DivolandiaLabs/preview-volume/releases/latest).
2. Запустите его и нажмите **Установить**. Установщик открывается на языке Windows, язык можно сменить слева внизу (10 языков). Программа ставится только для вашего пользователя, в `%LOCALAPPDATA%\Programs\Preview Volume`, без прав администратора.
3. Выберите, запускать ли её вместе с Windows и нужен ли ярлык на рабочем столе.

![Установщик](docs/screenshots/instalador.png)

Программа не подписана, поэтому при первом запуске Windows SmartScreen может показать предупреждение: нажмите **Подробнее → Выполнить в любом случае**.

Удаление: **Параметры → Приложения → Установленные приложения → Preview Volume → Удалить**.

Тихая установка: `PreviewVolume-Setup.exe /silencioso` (параметры: `/dir "папка"`, `/escritorio`, `/sininicio`, `/abrir`, `/idioma ru`).

## Использование

- Включите музыку в Spotify и наведите курсор на его значок на панели задач — над миниатюрой появится регулятор громкости.
- Перетащите ползунок, покрутите колесо мыши или щёлкните по динамику, чтобы отключить звук.
- Щёлкните правой кнопкой по зелёному значку рядом с часами, чтобы открыть меню: все приложения со звуком, запуск с Windows и выход.
- Закрыть из командной строки: `PreviewVolume.exe /salir`.

## Требования

- Windows 10 или 11 с .NET Framework 4.8 (уже входит в Windows).
- Проверено в Windows 11 с классической панелью задач (в стиле Windows 10, например с ExplorerPatcher). Миниатюры новой панели задач Windows 11 могут работать иначе.
- Установщик доступен на 10 языках; полоска и меню программы — на испанском.

## Сборка из исходного кода

Ничего устанавливать не нужно: сборка идёт компилятором C#, который есть в Windows.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Получаются `bin\PreviewVolume.exe` и установщик `bin\PreviewVolume-Setup.exe`. Значок рисует сама программа.

## Конфиденциальность

Preview Volume никогда не подключается к интернету и не собирает никаких данных. Единственная настройка хранится в файле `config.ini` рядом с программой.
